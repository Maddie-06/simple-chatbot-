# 🤖 Simple Chatbot

A basic AI chatbot built using Python, NLTK, and Scikit-learn.  
This chatbot uses text similarity and machine learning concepts to answer simple user questions.

---

## ✨ Features

- Simple command-line chatbot
- Uses Natural Language Processing (NLP)
- Text similarity using Cosine Similarity
- Built with Scikit-learn
- Beginner-friendly project
- Supports custom questions and answers

---

## 🛠️ Technologies Used

- Python
- NLTK
- Scikit-learn
